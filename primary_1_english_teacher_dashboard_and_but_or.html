Google Apps Script Setup Guide

Step 1: Create Google Sheet

Create a new Google Sheet and name columns in row 1: Timestamp, StudentName, Class, Score, Level, CommonMistakes.

Step 2: Add Apps Script

Go to Extensions > Apps Script, clear existing code, and paste the code snippet below:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.Timestamp,
    data.StudentName,
    data.Class,
    data.Score,
    data.Level,
    data.CommonMistakes
  ]);
  return ContentService.createTextOutput(JSON.stringify({"status":"success"})).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var headers = rows[0];
  var result = [];
  for (var i = 1; i < rows.length; i++) {
    var obj = {};
    for (var j = 0; j < headers.length; j++) {
      obj[headers[j]] = rows[i][j];
    }
    result.push(obj);
  }
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}

Step 3: Deploy as Web App

Click Deploy > New deployment. Select type: Web app. Execute as: Me. Who has access: Anyone. Copy the generated Web App URL and paste it into both GOOGLE_APPS_SCRIPT_URL variables in the student app and teacher dashboard.
